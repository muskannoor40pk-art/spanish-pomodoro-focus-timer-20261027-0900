## Overview
The Pomodoro Focus Timer is a lightweight, browser-based productivity tool designed specifically for users in Latin America and Spain. It removes the friction of complex settings, allowing you to dive straight into deep work sessions. Whether you are a student or a professional, this tool helps you maintain focus using the proven Pomodoro Technique.

## Features
*   **Customizable Sessions:** Easily adjust work and break durations to fit your personal workflow.
*   **Visual Progress:** A modern, circular progress ring that provides at-a-glance status updates.
*   **Session Tracking:** Keep count of your completed sessions to stay motivated throughout the day.
*   **Responsive Design:** Optimized for both desktop and mobile browsers using Flexbox and CSS Grid.
*   **Zero Dependencies:** Built with pure Vanilla JavaScript for lightning-fast performance.
